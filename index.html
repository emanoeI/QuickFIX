o que ele faz

8 módulos, zero instalação.

Roda direto da memória ou do arquivo local. Cada módulo é isolado — uma falha não afeta os outros.

MOD 01

Diagnóstico de Hardware

Fotografia completa da máquina em segundos — processador, memória, armazenamento e placa de vídeo num só relatório.

  • CPU modelo, núcleos e frequência
  • RAM por slot com velocidade real
  • Disco SSD/HDD com alerta de espaço baixo
  • GPU e versão do driver instalado
  • OS build, placa-mãe e fabricante
MOD 02

Diagnóstico de Rede

Verifica tudo de uma vez: IP local, DNS, gateway, IP público e latência — sem abrir nenhuma janela extra.

  • IP privado, DHCP e servidores DNS
  • IP público e provedor via ip-api
  • Gateway e conectividade com a internet
  • Ping médio com 4 amostras
MOD 03

Gerenciador de Impressoras

Resolve os problemas mais comuns de impressão sem precisar abrir Painel de Controle ou reiniciar o Windows.

  • Status e fila de jobs de cada impressora
  • Spooler — reiniciar e limpar fila travada
  • Padrão — troca a impressora padrão
  • Online — força status e imprime página de teste
MOD 04

Limpeza de RAM

Libera memória RAM sem fechar nenhum programa — especialmente útil quando o Chrome está engolindo tudo.

  • psapi.dll — limpeza nativa do Windows
  • Chrome/Edge sem perder nenhuma aba aberta
  • Tab Discarding — descarta abas inativas automaticamente
MOD 05

Reparo de Rede

Executa os comandos clássicos de reparo de rede em sequência — o equivalente a tudo que um técnico faria manualmente.

  • Release/Renew — renova o IP do adaptador
  • Winsock reset — corrige falhas de protocolo
  • Flush DNS — limpa cache de DNS isolado
  • Reset físico do adaptador de rede
MOD 06

Reparo do Windows

Verifica e restaura arquivos corrompidos do sistema — os mesmos comandos que a Microsoft recomenda, em ordem correta.

  • DISM RestoreHealth — repara a imagem do Windows
  • SFC /scannow — verifica arquivos de sistema
  • WinSxS — limpeza do repositório de componentes
MOD 07

Limpeza de Temporários

Remove arquivos temporários acumulados que ocupam espaço sem servir para nada — sem apagar nada importante.

  • %TEMP% — pasta temporária do usuário atual
  • C:\Windows\Temp — temporários do sistema
  • Prefetch — cache de inicialização de apps
MOD 08

Klingo — Reset de PWA

Reinstala o aplicativo Klingo do zero quando ele trava ou apresenta comportamento estranho, sem afetar outros apps.

  • Desinstalação limpa do PWA via Chrome
  • Cache, LocalStorage e IndexedDB removidos
  • Perfil — seleciona qual perfil do Chrome usar

por que existe
01

Problema real

Mesmo diagnóstico, executado de formas diferentes por técnicos diferentes. Sem registro, sem padrão, sem rastreabilidade.

02

Solução construída no estágio

Desenvolvido durante o período de estágio, testado em máquinas reais do ambiente corporativo. Não é projeto de faculdade — é ferramenta em uso.

03

Relatório automático por sessão

Cada atendimento gera um .txt com técnico, máquina, IP e resultado de cada ação. Auditável e arquivável sem esforço extra.

04

Zero dependência

Roda em qualquer Windows 10/11 com PS5 nativo. Sem instalar nada, sem precisar de admin de domínio, sem configuração prévia.

como usar

Pronto em uma linha.

Sem instalação. Cole no PowerShell e rode.

# proxy-friendly — executa direto da memória
$wc = New-Object Net.WebClient
$wc.Proxy.Credentials = [Net.CredentialCache]::DefaultNetworkCredentials
IEX $wc.DownloadString('https://raw.githubusercontent.com/emanoeI/QuickFIX/main/QuickFIX.ps1')
# salva o arquivo antes de executar
$wc = New-Object Net.WebClient
$wc.Proxy.Credentials = [Net.CredentialCache]::DefaultNetworkCredentials
$wc.DownloadFile('https://raw.githubusercontent.com/emanoeI/QuickFIX/main/QuickFIX.ps1', 'QuickFIX.ps1')
powershell -ExecutionPolicy Bypass -File .\QuickFIX.ps1
# método curto
powershell -ExecutionPolicy Bypass -Command "iex (irm https://raw.githubusercontent.com/emanoeI/QuickFIX/main/QuickFIX.ps1)"
